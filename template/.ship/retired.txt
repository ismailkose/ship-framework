# Framework files Ship no longer ships. The installer (setup.sh / ship-update.sh) removes
# them from projects on update: an unedited copy is deleted; an edited copy is moved to
# .ship/backups/<stamp>/ first. User-owned files are never touched, even if listed here.
#
# One project-relative path per line. `dir/` retires everything under it; `*` globs work.
# Only paths inside Ship's namespace (.claude/skills/ship/**, .claude/skills/shipmate/**,
# .claude/commands/ship-*.md,
# .claude/skills/ship-*/, .claude/agents/ship-*.md, .claude/team-rules.md) or files that are
# byte-identical to a past Ship release are acted on. Anything else is ignored with a note.
#
# Files Ship installed (listed in a project's .ship/manifest.json) and no longer ships are
# retired automatically — this list is for projects installed before manifests existed
# (≤ 2026.09.22) and for anything you want removed even when a user edited it.
